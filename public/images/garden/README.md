# Garden images

Student artwork and scanned care sheets for the /garden section.

Expected filenames (one pair per plant, matching the `id` in
`content/3rd-period-garden/plants.json`):

- `<id>-plant.jpg` — the student's drawing of the plant (shown on the info page and the index card)
- `<id>-care.jpg` — the scan of the student's handwritten care sheet

For example: `black-eyed-susan-plant.jpg`, `black-eyed-susan-care.jpg`.

Pages show a styled placeholder for any file that isn't here yet, so images can be
added a few at a time.

Before committing a photo, crop it to the page edges and resize it to about 1200px
on the long side. The originals are phone-camera size (~2.5 MB each), which is far
too heavy for a live page.
